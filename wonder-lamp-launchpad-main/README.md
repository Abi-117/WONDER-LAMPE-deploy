# Wonder Lampe Launch

Build a premium, high-converting SINGLE-PAGE landing page for Wonder Lampe Academy's ₹299 Share Market Learning Program using the uploaded specification document and assets (official Wonder Lampe Academy logo and Dr. M. Madhankumar mentor portrait).

Strict requirements:
- 100% English only (no Tamil anywhere).
- Premium Light Theme (#F8FAFC / #FFFFFF, Primary Gold #D4A017, Bright Gold #F5C542, Emerald Green #16A34A, Soft Gold #FFF8E1, Border #E2E8F0, Dark text #111827).
- Sticky header with logo, navigation links, and "JOIN FOR ₹299" CTA.
- Strong hero section with badge, headline, pricing highlight, trust markers, and interactive financial dashboard cards / stock chart visuals.
- Offer bar, 6 problem cards, ₹299 offer intro, 5 core benefit cards (Recorded Classes, 21 Days Live Online Training, Complete Study Materials, AI Stock & Portfolio Access, Premium Community).
- Value stack, full curriculum breakdown, 21-day timeline journey, "Who Is This Program For?" profile cards, "Why Wonder Lampe Academy?" statistics (1,220+ enrolled, 520+ certified, 31+ teachers, 5+ courses).
- Mentor section for Dr. M. Madhankumar using the uploaded portrait photo with editable credentials structure and clean presentation.
- Testimonial cards, social links (Instagram & Facebook), 4-step "How It Works" guide, accordion FAQ.
- Registration modal/form with name, mobile, email, city, WhatsApp number, experience level, and mandatory market risk acknowledgement checkbox.
- Multi-step payment/success flow leading to the registration success screen and configurable WhatsApp community join button.
- Floating/sticky mobile bottom CTA and central configuration file for easily updating links, pricing, and mentor details.
